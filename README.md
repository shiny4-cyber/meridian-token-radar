# Meridian — Token Radar

Original offline research workspace for token-radar-01. Build and local verification only; no publication or submission performed.

## Run

Requires Node >=22.18, standard library only. No npm install or runtime network.

    MAKEFUN_OUTPUT_DIR=/absolute/output node main.ts --input /absolute/path/snapshot.json
    npm test
    python3 tests/browser_test.py --output /absolute/output --captures /absolute/captures

The default input is /input/snapshot.json and default output /output. Keep generated output outside this repository. For first-time screenshot capture, add --preview (intentionally omits dossier). The browser test requires installed Python Playwright and Firefox; it starts an available localhost port, verifies interactions, captures three 1440x900 JPEGs and shuts down its server/browser. Copy those captures to screenshots/ and rebuild normally.

Serve output/dashboard with a local static server to inspect it. file:// is unsupported because the browser fetches records.dat from the same static origin. That file is plain JSON, generated by main.ts and byte-identical to board.json. No external requests, CDN, wallet connection or sample data are used.

## Model

All 758 snapshot rows are ranked; all 40 official watchlist entries are included. Default research candidates exclude structural-product heuristics from no-token-recorded records. All no-token records and token-recorded benchmarks remain separately inspectable.

Scenario market capitalization = capped TVL × median bounded comparable market-cap/TVL ratio × bounded seven-day growth factor × listing-age factor × structural factor. Category peers require four independent token identities; otherwise global fallback, then a 0.25 prior. Token clones are deduplicated and the scored token identity is excluded. Ratios clamp to 0.05–5, growth to -50–100%, TVL to $1T. Listing age is not operating age or time without a token. Missing age uses 0.70, missing growth uses neutral adjustment. A source market-cap -1 sentinel is preserved but excluded from peers. Full calculation and conditional farm plans are in dashboard/model.mjs and the methodology dialog.

Ranges are sensitivity scenarios, not probability intervals. Market capitalization is not FDV, TVL, token price, expected reward or a launch prediction. Parent relationships, revenue, supply, unlocks, official URLs and campaign terms are absent. Structural heuristics are imperfect. Farm budgets and durations are planning estimates; product availability must be verified, principal can be lost and rewards may be zero.
